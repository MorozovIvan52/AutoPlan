# Партнёрская программа

Цель: привлечь интеграторов и партнёров по внедрению/телефонии/поставщикам запчастей.

Уровни:
- Referral: приведи клиента — получи комиссию (X% за первый год)
- Certified Partner: обучение, доступ к API, приоритет в leads
- Integration Partner: SDK, co-marketing, revenue-share

Что подготовить:
- Документы: SLA, договор партнёра, прайс-лист
- Портал партнёра (регистрация, leads, документация)
- API keys и тестовая среда (sandbox)

Срок: запуск базовой программы — 2 недели.
