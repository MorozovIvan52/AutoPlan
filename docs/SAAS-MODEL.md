# Модель распространения: SaaS (Вариант A)

## Суть

Клиенты работают в CRM через браузер по единому домену **crm.ваш-бренд.ru** (или white-label поддомен `клиент.ваш-бренд.ru`).

| Преимущество | Описание |
|--------------|----------|
| Централизация | Один сервер, обновления, бэкапы, мониторинг |
| Единая кодовая база | Исправления и фичи — всем сразу |
| Подписка | Предсказуемый доход MRR/ARR |
| Онбординг | Мастер настройки, база знаний, видео |

## Архитектура (текущая → целевая)

```
Сейчас (MVP)                    Целевая SaaS-платформа
─────────────────               ──────────────────────
1 VPS                           Кластер / несколько VPS
SQLite на инстанс               PostgreSQL + tenant_id
1 организация                   Мультитенант
Ручной deploy                   GitHub Actions CI/CD
```

Текущая версия продукта — **мультитенантная подготовка на SQLite** (один сервер, `tenant_id` на данных).  
Для масштабирования SaaS запланирован переход на **PostgreSQL + RLS** (см. `docs/ops/POSTGRES-RLS.md`).

Официальное название продукта: **CRM АвтоПлан**.

## Тарифы (пример)

| Тариф | Пользователи | Каналы | Цена/мес |
|-------|--------------|--------|----------|
| Старт | до 3 | 2 Авито + 1 мессенджер | 4 990 ₽ |
| Бизнес | до 10 | без лимита каналов | 12 990 ₽ |
| Филиал | до 25 | + телефония, СДЭК, API | 24 990 ₽ |

Годовая оплата: **−15%**. Доп. пользователь: **+990 ₽/мес**.

## Онбординг клиента

1. Регистрация / договор и оплата.
2. Создание организации (вручную или self-service).
3. Выдача admin@клиент-домен.ru, ссылка на [базу знаний](../knowledge-base/getting-started.md).
4. Подключение Авито/Telegram (видео №7–8).
5. Чеклист через 7 дней: входящие, шаблоны, 1 сделка.

## White-label (опционально)

- Поддомен: `autoservice-ivanovo.ваш-бренд.ru`
- Логотип и цвета: `data-theme` + настройки CRM
- Отдельный `PUBLIC_URL` и SSL через Certbot wildcard или отдельный сертификат

## Метрики бизнеса

- MRR, churn, LTV
- DAU операторов
- Сообщений/день на тенант
- Uptime по [SLA](./legal/SLA.md)
