# Политика конфиденциальности

**Дата публикации:** [ДД.ММ.ГГГГ]  
**Редакция:** 1.0

Настоящая Политика определяет порядок обработки персональных данных оператором **[ПОЛНОЕ НАИМЕНОВАНИЕ ЮРЛИЦА / ИП]** (ИНН [номер], ОГРН/ОГРНИП [номер], адрес: [адрес], email: [privacy@ваш-бренд.ru], далее — **Оператор**) при использовании **AutoService CRM** (далее — **Сервис**).

Политика разработана в соответствии с Федеральным законом № 152-ФЗ «О персональных данных».

---

## 1. Какие данные обрабатываются

### 1.1. Данные пользователей CRM (сотрудников Клиента)

- ФИО, email, телефон, роль в системе;
- IP-адрес, cookies, журнал действий (логи входа);
- настройки интерфейса (тема, уведомления).

### 1.2. Данные, вводимые Клиентом о своих клиентах

- имена, телефоны, VIN, адреса, переписка, заказы, файлы и медиа;
- идентификаторы на площадках (Авито, Telegram и др.).

**Оператор обрабатывает эти данные по поручению Клиента** как обработчик (если применимо) — в целях предоставления Сервиса.

### 1.3. Технические данные

- метрики сервера, резервные копии БД (зашифрованное хранилище S3);
- обезличенная аналитика использования.

## 2. Цели обработки

| Цель | Правовое основание |
|------|-------------------|
| Предоставление доступа к CRM | Договор / согласие |
| Техподдержка и безопасность | Законный интерес / договор |
| Исполнение 152-ФЗ (учёт обращений) | Закон |
| Маркетинг Оператора (новости продукта) | Согласие (отдельная галочка) |

## 3. Передача третьим лицам

Данные могут передаваться:

- хостинг-провайдеру (VPS в РФ);
- S3-хранилищу (бэкапы) — [Yandex Cloud / иное];
- интеграциям по инициативе Клиента: Авито, Telegram, СДЭК, Yandex GPT и др. — по API Клиента.

Трансграничная передача: только при наличии правовых оснований и уведомления, если применимо.

## 4. Срок хранения

- Данные аккаунта — на срок договора + [90] дней для выгрузки/аудита.
- Резервные копии — [30] дней (ротация).
- Логи безопасности — до [12] месяцев.

По запросу на удаление — в срок до [30] дней, кроме данных, которые обязаны храниться по закону.

## 5. Меры защиты

- HTTPS (TLS 1.2+);
- хеширование паролей (соль + стойкий алгоритм);
- разграничение ролей в CRM;
- ежедневные бэкапы, ограничение доступа к серверу по SSH-ключу;
- мониторинг доступности и инцидентов.

## 6. Права субъекта данных

Вы вправе:

- получить информацию об обработке;
- требовать уточнения, блокирования или удаления данных;
- отозвать согласие (если обработка на согласии);
- обжаловать действия Оператора в Роскомнадзор.

Запрос: [privacy@ваш-бренд.ru], срок ответа — до [30] дней.

## 7. Cookies

Сервис использует cookies для сессии авторизации (`credentials: include`). Отключение cookies делает вход невозможным.
