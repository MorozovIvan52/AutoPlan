# Лицензионный договор‑оферта CRM АвтоПлан

Полный текст формируется из env (`LICENSOR_*`) в `api/lib/license-offer-text.ts` и показывается на экране `/accept-offer`.

## Акцепт

1. Пользователь входит в CRM.
2. Если тенант не принял текущую версию оферты — редирект на `/accept-offer`.
3. Читает договор → галочка согласия → телефон → SMS‑код → подтверждение.
4. Факт акцепта пишется в `tenants` (`offer_accepted_at`, `offer_accepted_phone`, `offer_version`).

Демо‑аккаунты (`role=demo`) оферту не проходят.

## Env

См. `.env.example` (блок «Лицензиар» + `SMS_API_ID`).
