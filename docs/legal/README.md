## Публикация на сайте

Рекомендуемые URL:

- `/legal/terms` — пользовательское соглашение
- `/legal/privacy` — политика конфиденциальности  
- `/legal/sla` — SLA

На экране входа — чекбокс «Принимаю [условия](...) и [политику](...)».

## Подписание с B2B-клиентом

Для юрлиц дополнительно: договор оказания услуг, акт, счёт, приложение с тарифом и SLA.
