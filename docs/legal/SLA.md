# Соглашение об уровне обслуживания (SLA)

**Дата публикации:** [ДД.ММ.ГГГГ]  
**Редакция:** 1.0  
**Применяется к:** тарифам SaaS **AutoService CRM**  
**Оператор:** [ПОЛНОЕ НАИМЕНОВАНИЕ ЮРЛИЦА / ИП]

---

## 1. Определения

| Термин | Значение |
|--------|----------|
| **Сервис** | CRM, доступная по HTTPS |
| **Аптайм** | Доля времени, когда `GET /api/health` возвращает `"status":"ok"` |
| **Плановые работы** | Обновления, миграции с предварительным уведомлением |
| **Инцидент** | Недоступность или критическая деградация Сервиса |
| **RTO** | Целевое время восстановления |
| **RPO** | Допустимая потеря данных при восстановлении из бэкапа |

## 2. Гарантии доступности

| Тариф | Аптайм / месяц | Исключения |
|-------|----------------|------------|
| Старт | **99.0%** | п. 3 |
| Бизнес | **99.5%** | п. 3 |
| Филиал | **99.9%** | п. 3 |

**99.5%** ≈ не более **3 ч 39 мин** простоя в месяц.

Мониторинг: внешняя проверка `/api/health` каждые 60 секунд.

## 3. Не учитывается в аптайме

- плановые работы (уведомление за **24 ч** по email);
- сбои DNS/Интернет у Клиента, DDoS вне контроля Оператора;
- недоступность API третьих сторон (Авито, Telegram, СДЭК, платёжные системы);
- действия/бездействие Клиента, нарушение Соглашения;
- форс-мажор.

## 4. Поддержка

| Канал | Время | Тариф Старт | Бизнес | Филиал |
|-------|-------|-------------|--------|--------|
| Email support@… | Пн–Пт 09:00–18:00 МСК | ответ **24 ч** | **8 ч** | **4 ч** |
| Telegram (критичные) | 24/7 приём | — | **12 ч** | **2 ч** |
| Телефон | по договору | — | — | да |

**Критичный инцидент** — полная недоступность входа или API для всех пользователей организации.

## 5. Резервное копирование

| Параметр | Значение |
|----------|----------|
| Частота | ежедневно, 03:00 UTC |
| Хранение | **30** дней |
| RPO | **24** часа |
| RTO | **4** часа (тариф Филиал), **8** часов (остальные) |

Восстановление из бэкапа — по запросу Клиента или при катастрофическом сбое.

## 6. Компенсации при нарушении аптайма

При подтверждённом нарушении аптайма за календарный месяц (по данным мониторинга Оператора):

| Фактический аптайм | Компенсация |
|--------------------|-------------|
| ниже гарантии, но ≥ 99.0% | **5%** от месячной платы |
| 98.0% – 98.99% | **10%** |
| 95.0% – 97.99% | **25%** |
| ниже 95.0% | **50%** |

Компенсация — зачёт в следующем периоде или возврат по выбору Клиента. Максимум **50%** месячной платы. Не распространяется на тариф «Старт» при аптайме выше 99.0%, если иное не в договоре.

Заявка на компенсацию — в течение **14** дней после месяца инцидента на [support@ваш-бренд.ru].

## 7. Ограничение ответственности

Совокупная ответственность Оператора по SLA не превышает сумму оплаты за **1** месяц. SLA не покрывает упущенную выгоду Клиента.

## 8. Оплата и приостановка

| Событие | Действие |
|---------|----------|
| За **7** и **3** дня до конца периода | напоминание об оплате |
| Просрочка **5** дней | режим **только чтение** |
| Просрочка **14** дней | блокировка доступа, данные хранятся **90** дней |

## 9. Отчётность

По запросу (тариф Бизнес и выше) — отчёт об аптайме за месяц в течение **10** рабочих дней.
