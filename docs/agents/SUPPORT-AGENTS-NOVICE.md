# Умная техподдержка (мультиагенты) — инструкция для новичка

В CRM уже встроен чат **«Умная техподдержка»** (кружок справа внизу).  
Это **не** Cursor Cloud Agents. Здесь агенты отвечают **внутри CRM** клиенту/сотруднику через Yandex GPT или Claude.

---

## 1. Что вы получаете (простыми словами)

| Агент | Когда подключается | Чего не делает |
|-------|--------------------|----------------|
| **Менеджер** | Обычные вопросы, запись | Не называет финальную цену без осмотра |
| **Бухгалтер** | Счёт, НДС, акт, возврат | Не обещает «вернём деньги сразу» |
| **Юрист** | Гарантия, претензия | Не даёт 100% гарантий |
| **Механик** | Стучит, ремонт, запчасти | Не ставит диагноз дистанционно |
| **Разработчик** | Баг CRM, Авито, SMS | Не лезет в сервер/БД |
| **Дизайнер** | Неудобный интерфейс | Не меняет UI сам |

**Как это работает:**

```
Вы пишете в чат
    → система по словам выбирает 1–2 агента
    → каждый даёт короткий ответ (LLM)
    → ответы склеиваются в один
    → если нужно — создаётся задача «эскалация» для живого оператора
```

Код уже на сервере (`api/lib/agent-prompts.ts`, `api/lib/support-orchestrator.ts`, виджет в углу).  
Вам нужно только: **ключ AI → проверка → пользоваться**.

## 2. Два разных «агента» — не путайте

| | Умная техподдержка (этот гайд) | Cursor Cloud Agents |
|--|--------------------------------|---------------------|
| Где | Сайт CRM, кружок «Поддержка» | Cursor.com / Automations |
| Для кого | Сотрудник СТО / клиент в CRM | Владелец продукта, аналитика |
| Что делает | Отвечает на вопрос прямо сейчас | Утренний брифинг, отчёты по коду |
| Инструкция | **Этот файл** | [CLOUD-AGENTS-SETUP.md](./CLOUD-AGENTS-SETUP.md) |

Сначала настройте **этот** чат. Cloud Agents — по желанию позже.

## 3. Шаг за шагом: включить ответы ИИ

Без ключа чат откроется, но ответит ошибкой вроде «AI не настроен».

### Шаг 3.1. Выберите провайдера (один достаточно)

**Вариант A — YandexGPT** (часто уже есть у проекта):

1. Зайдите в [console.yandex.cloud](https://console.yandex.cloud).
2. Создайте каталог (folder) → скопируйте **Folder ID**.
3. Создайте API-ключ сервисного аккаунта с ролью на YandexGPT.
4. Запишите:
   - `YANDEX_API_KEY=...`
   - `YANDEX_FOLDER_ID=...`

**Вариант B — Claude / OpenAI-совместимый API** (приоритетнее Yandex, если оба заданы):

```env
AI_BASE_URL=https://ваш-прокси.example.com
AI_API_KEY=sk-...
AI_MODEL=claude-opus-4-8
```

### Шаг 3.2. Прописать ключи на VPS (прод)

1. Подключитесь по SSH к серверу CRM (у вас обычно хост `crm-vps`).
2. Откройте файл окружения, например:

```bash
nano /opt/crm/.env
```

(если `.env` лежит рядом с приложением — правите тот файл, из которого PM2 читает переменные).

3. Добавьте строки (без кавычек, без пробелов вокруг `=`):

```env
YANDEX_API_KEY=ваш_ключ
YANDEX_FOLDER_ID=ваш_folder_id
```

или

```env
AI_API_KEY=...
AI_BASE_URL=...
AI_MODEL=...
```

4. Сохраните файл.
5. Перезапустите CRM:

```bash
cd /opt/crm
pm2 restart crm
pm2 logs crm --lines 30
```

Убедитесь, что процесс `online`, без красных ошибок при старте.

### Шаг 3.3. Локально (если тестируете на своём ПК)

В корне проекта файл `.env` (он **не** в git):

```env
YANDEX_API_KEY=...
YANDEX_FOLDER_ID=...
```

Затем:

```bash
npm run dev
```

## 4. Шаг: проверить, что AI видит CRM

В браузере (нужна сессия админа) откройте:

```
https://crmavito.online/api/ai/status
```

или локально:

```
http://localhost:4200/api/ai/status
```

Ожидаете что-то вроде `configured: true` (точный JSON может отличаться).  
Если `false` / ошибка — ключи не подхватились: проверьте `.env` и `pm2 restart`.

## 5. Шаг: пользоваться чатом в интерфейсе

1. Откройте [https://crmavito.online](https://crmavito.online) и **войдите** (гость чат не видит).
2. Справа внизу найдите кружок **«Поддержка»** / 💬.
3. Нажмите → откроется окно **«Умная техподдержка»**.
4. Напишите вопрос и Enter (или «Отправить»).
5. Под ответом увидите метку агентов, например: `manager · accountant`.

### Фразы для проверки каждого агента

Скопируйте по одной:

| Напишите в чат | Должен подключиться |
|----------------|---------------------|
| `Хочу записаться на диагностику` | manager |
| `Нужен акт сверки и счёт с НДС` | accountant (+ часто manager) |
| `Какая гарантия на ремонт и как подать претензию?` | lawyer |
| `Что-то стучит в подвеске, что менять?` | mechanic |
| `В CRM не сохраняется заказ, баг` | developer |
| `Кнопка на странице ЗН непонятная` | designer |

Хороший ответ: короткий, без «вернём за минуту» / «гарантируем 100%» / «точно завтра починим».

## 6. Что происходит при «сложном» вопросе

Если агент пишет **«требуется человек»** или тема похожа на баг/претензию:

1. В таблице **`tasks`** создаётся задача с типом **`escalation`**.
2. Клиенту в чат добавляется фраза вроде: оператор ответит в течение **15 минут**.
3. Сообщения пишутся в **`messages`** с полем **`agent_type`** (кто отвечал).

**Как посмотреть задачи:**

- В CRM раздел **Задачи** (`/tasks`), или
- на сервере (для админа):

```bash
# пример для SQLite на VPS
cd /opt/crm
sqlite3 crm.db "SELECT id, title, task_type, status, created_at FROM tasks WHERE task_type='escalation' ORDER BY id DESC LIMIT 10;"
```

## 7. Проверка через curl (по желанию)

1. Войдите в CRM в браузере.
2. Скопируйте cookie сессии (DevTools → Application → Cookies), либо используйте сохранённый файл cookies.
3. Запрос:

```bash
curl -b cookies.txt -X POST https://crmavito.online/api/support/chat \
  -H "Content-Type: application/json" \
  -d "{\"message\":\"Нужен акт сверки с НДС\"}"
```

Ответ примерно:

```json
{
  "conversationId": 123,
  "response": "…текст…",
  "agentsUsed": ["manager", "accountant"],
  "escalated": false
}
```

## 8. Где лежат файлы (если захотите поменять тексты)

| Файл | Зачем |
|------|--------|
| `api/lib/agent-prompts.ts` | Системные промты агентов (тон, запреты) |
| `api/lib/support-orchestrator.ts` | Выбор агента, вызов LLM, эскалация |
| `api/routes/support/chat.ts` | HTTP: `POST /api/support/chat` |
| `src/components/SupportChatWidget.tsx` | Кружок и окно чата |
| `api/lib/llm.ts` | Подключение Yandex / AI_* |

После правок промтов:

```bash
npm run deploy:vps
```

(или локально перезапуск `npm run dev`).

Подстановка названия СТО: в промтах есть `{{tenantName}}` и `{{tenantPlan}}` — подставляются из тенанта автоматически.

## 9. Чеклист «всё работает»

- [ ] В `.env` на VPS есть `YANDEX_*` **или** `AI_*`
- [ ] `pm2 restart crm` выполнен после правок `.env`
- [ ] `/api/ai/status` показывает, что AI настроен
- [ ] После входа виден кружок «Поддержка»
- [ ] Вопрос про НДС даёт ответ бухгалтера (без обещания мгновенного возврата)
- [ ] Вопрос «стучит» предлагает диагностику, а не «меняйте рычаг»
- [ ] При эскалации появляется задача в `/tasks`

## 10. Частые проблемы

| Симптом | Что сделать |
|---------|-------------|
| Нет кружка | Вы не залогинены; обновите страницу (Ctrl+F5) |
| «AI не настроен» | Ключи в `.env`, перезапуск PM2, проверка `/api/ai/status` |
| «Высокая нагрузка… 2 минуты» | LLM не ответил за 10 сек — проверьте ключ/лимиты Yandex или сеть |
| Ответы «общие», не про ваше СТО | В настройках/тенанте заполните название компании |
| Путаете с Cloud Agents | Этот чат — в CRM; Cloud — в Cursor Automations ([гайд](./CLOUD-AGENTS-SETUP.md)) |

---

## 11. Порядок действий на один вечер (кратко)

1. Получить `YANDEX_API_KEY` + `YANDEX_FOLDER_ID` (или `AI_*`).
2. Вписать в `/opt/crm/.env` → `pm2 restart crm`.
3. Открыть CRM → войти → кружок «Поддержка».
4. Прогнать 4–5 тестовых фраз из таблицы выше.
5. Открыть `/tasks` и убедиться, что при «баге» появляется эскалация.
6. (Опционально) Настроить Cursor Cloud Agents по `CLOUD-AGENTS-SETUP.md` для утренних отчётов.

Код агентов **внедрять заново не нужно** — он уже в проде. Ваша работа: **ключи + проверка + привычка пользоваться чатом**.
