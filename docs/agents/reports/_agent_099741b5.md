## Рекомендация

**Оставаться на SQLite**, пока владелец не скажет «готов к Postgres».

Когда скажет — порядок из pre-flight (только после «ДА»):

1. Бэкап `crm.db` (хранить ≥7 дней)
2. Поднять Postgres 15+ / managed, рабочий `DATABASE_URL`
3. `npm run db:push` (или согласованная схема)
4. `psql "$DATABASE_URL" -f scripts/setup-postgres-rls.pgsql`
5. `PG_RLS=1`
6. `npm run migrate:postgres` → `npm run verify:postgres`
7. `npm run pg:ensure-modules` → `npm run verify:pg-modules`
8. `npm run pilot:seed:clean && npm run pilot:verify` + проверка изоляции sto-1 vs sto-2  

**Rollback:** убрать `DATABASE_URL`, `pm2 restart crm` → снова SQLite `crm.db`.
