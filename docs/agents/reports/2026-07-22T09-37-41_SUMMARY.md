**Логика отбора по разделам брифинга:**

- **Входящие без ответа** — `chat_sla` где `last_inbound_at > last_outbound_at` ИЛИ `last_outbound_at IS NULL`, плюс `sla_breached = true`. Возраст считается в `chat-sla.ts` от `last_inbound_at`.
- **ЗН без обновления > 48 ч** — `service_deals` где `status IN ('open','in_progress')` И `updated_at < now() - interval '48 hours'`.
- **Записи на сегодня** — `service_appointments` где `scheduled_at::date = current_date`.
- **Нулевые остатки + активные ЗН** — JOIN `inventory` (qty ≤ 0) ↔ `service_deal_parts` ↔ `service_deals` (status активен).
- **Просроченные задачи** — `tasks` где `due_at < now()` и `status NOT IN ('done','cancelled')` — роут `GET /tasks/overdue` или эквивалент в `routes/tasks.ts`.

## 1. Диалоги с высоким intent без ответа

**Маркеры intent** (из логики `scanChatOpportunities`): `ремонт`, `цена`, `стоимость`, `диагностика`, `VIN`, `сколько стоит`, `тормоза`, `ходовая`, `масло`.
**"Без ответа"**: последнее сообщение inbound, исходящих за последние 24ч нет.

```sql
SELECT
  c.id               AS conversation_id,
  c.client_id,
  c.deal_id,
  c.stage,
  c.last_message_at,
  m.body             AS last_message,
  EXTRACT(EPOCH FROM (now() - c.last_message_at))/3600 AS hours_idle
FROM conversations c
JOIN messages m ON m.id = c.last_message_id
WHERE m.direction = 'inbound'
  AND c.status   = 'open'
  AND m.body ~* '\m(ремонт|цена|стоимость|диагностика|vin|сколько стоит|тормоз|ходов|масл)\M'
  AND NOT EXISTS (
    SELECT 1 FROM messages m2
    WHERE m2.conversation_id = c.id
      AND m2.direction       = 'outbound'
      AND m2.created_at      > c.last_message_at - interval '24 hours'
  )
ORDER BY c.last_message_at DESC;
```

**Шаблон вывода строки:**
- `conversationId`, `clientId`, `dealId` — из выборки
- **Текст ответа:** «Здравствуйте, [Имя]! По вашему вопросу о [ремонте / стоимости / VIN…] — уточните, пожалуйста, [марка, модель, год / что именно сломалось / какой узел]. Тогда дам точную цену и сроки.»
- **Задача:** `title: "Ответить в диалоге {conversationId}"`, `dueAt: +2ч`, `priority: high`

## 2. Звонки за 24ч без связанной задачи

```sql
SELECT
  cl.id             AS call_id,
  cl.client_id,
  cl.deal_id,
  cl.phone,
  cl.direction,     -- in/out
  cl.duration_sec,
  cl.started_at,
  cl.recording_url
FROM call_logs cl
WHERE cl.started_at >= now() - interval '24 hours'
  AND NOT EXISTS (
    SELECT 1 FROM tasks t
    WHERE (t.call_id   = cl.id)
       OR (t.client_id = cl.client_id
           AND t.type   IN ('call_followup','callback')
           AND t.created_at >= cl.started_at)
  )
ORDER BY cl.started_at DESC;
```

**Если в схеме поле связи называется иначе** (например, `entity_id` + `entity_type`), замените блок `EXISTS`.

**Шаблон:**
- `callId`, `clientId`, `dealId`
- **Текст:** «[Имя], добрый день! По итогам нашего разговора в [HH:MM] уточняю: [вопрос из расшифровки/записи]. Удобно сейчас обсудить?»
- **Задача:** `title: "Перезвонить клиенту {clientId} после звонка {callId}"`, `dueAt: +3ч`, `priority: high` (если `duration_sec > 30` или клиент новый), иначе `normal`

## 3. Follow-up «перезвонить» без `dueAt`

```sql
SELECT
  t.id           AS task_id,
  t.client_id,
  t.deal_id,
  t.title,
  t.type,
  t.priority,
  t.created_at,
  t.assignee_id
FROM tasks t
WHERE t.type IN ('callback','followup','перезвонить','call_back')
  AND t.status IN ('open','pending','new')
  AND (t.due_at IS NULL OR t.due_at < now())
ORDER BY t.created_at ASC;
```

**Шаблон:**
- `taskId`, `clientId`, `dealId`
- **Текст:** «[Имя], договаривались перезвонить по [тема]. Уточню детали и предложу варианты — удобно сейчас или назначим время?»
- **Задача:** `title: "Проставить срок и назначить перезвон по задаче {taskId}"`, `dueAt: +1ч`, `priority: normal`
