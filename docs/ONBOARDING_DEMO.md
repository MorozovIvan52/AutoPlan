# Быстрый демо‑флоу (Onboarding)

Цель: дать потенциальному клиенту рабочий тест‑аккаунт за 1–2 минуты.

Шаги:
1. Landing → кнопка "Попробовать бесплатно" → автоматическая регистрация тест‑тенанта
2. Заполнение минимальных данных (название СТО, email, телефон)
3. Автогенерация примера данных (10 клиентов, 5 машин, 3 заказа‑наряда)
4. Показ видео‑обзора 3–5 минут и walkthrough (в модальном окне)
5. CTA: подключить карту / перейти на тариф (+10% от STOCRM)

Технически:
- endpoint `POST /api/v1/onboarding/test-tenant`
- seed data script `scripts/seed-demo.ts`
- страница `src/pages/onboarding/DemoPage.tsx`
