# Быстрый старт

## 1. Вход в CRM

1. Откройте адрес вашей CRM (например `https://crm.ваш-бренд.ru/login`).
2. Введите email и пароль, выданные администратором.
3. При первом входе смените пароль: **Настройки → Пользователи**.

## 2. Главный экран — Входящие

| Элемент | Назначение |
|---------|------------|
| Список слева | Все диалоги (Авито, Telegram, WhatsApp и др.) |
| Вкладки «Все / Новые / Мои» | Фильтр по непрочитанным и назначению |
| Поиск | По имени клиента, телефону, тексту чата |
| Чат по центру | Переписка с клиентом |
| Панель справа | Карточка клиента, теги, сделки, запись |

**Горячие клавиши:** `J` / `K` — следующий/предыдущий диалог, `/` — поиск, `Ctrl+K` — глобальный поиск.

## 3. Ответ клиенту

1. Выберите диалог в списке.
2. Введите текст внизу или выберите **шаблон** (иконка инструментов).
3. `Enter` — отправить, `Shift+Enter` — новая строка.
4. Можно прикрепить фото/файл или использовать **Алису** для подсказки ответа.

## 4. Сообщения Авито

- **Слева (серый пузырь)** — сообщение клиента.
- **Справа (синий)** — ваш ответ.
- **По центру (зелёный, «Авито»)** — системное уведомление платформы (оплата, заказ и т.д.), не отвечайте на него как клиенту.

## 5. Сделки и заказы

1. В чате: **Инструменты → Заказ** или откройте **Сделки** в меню.
2. Укажите товар, сумму, статус.
3. Для доставки: в карточке сделки блок **СДЭК**.

## 6. Запись на ремонт

**Инструменты → Запись** в чате или раздел **Календарь** в меню.

## 7. Мобильная версия

CRM работает в браузере телефона. Добавьте на главный экран (PWA): меню браузера → «На экран Домой».

## 8. Что настроить администратору

| Задача | Где |
|--------|-----|
| Подключить Авито | Настройки → Каналы |
| Telegram-бот | Настройки → Каналы |
| Шаблоны ответов | Настройки → Шаблоны |
| Операторы и роли | Настройки → Пользователи |
| Телефония Мегафон/МТС | Настройки → Телефония |
