# Полная инструкция: как запустить CRM для операторов (для новичка)

Эта инструкция рассчитана на человека **без опыта** в серверах и программировании.  
Следуйте шагам **по порядку**. Примеры с вымышленными данными — подставьте свои.

---

## Что вы получите в итоге

- Сайт CRM по адресу вида: `https://crm.ваш-сайт.ru`
- CRM работает **круглосуточно** (даже когда ваш компьютер выключен)
- Операторы заходят в браузере, видят чаты Авито/Telegram, заказы, записи на ремонт
- Все данные хранятся в файле базы `crm.db` на сервере

## Часть 0. Что нужно купить/подготовить

| Что | Зачем | Примерная цена |

- 1 CPU, 1–2 GB RAM, 10 GB диска

**Пример домена:** у вас есть сайт `autoservice-moscow.ru` → CRM можно повесить на поддомен `crm.autoservice-moscow.ru`.

## Часть 1. Сначала проверьте CRM у себя на компьютере (Windows)

Перед выкладкой в интернет убедитесь, что программа запускается локально.

### 1.1. Установите Node.js

1. Откройте https://nodejs.org
2. Скачайте версию **LTS** (кнопка «Download»)
3. Установите: везде нажимайте **Next** → **Install** → **Finish**
4. Откройте **PowerShell** (Win+R → введите `powershell` → Enter)
5. Проверьте:
   ```powershell
   node -v
   ```
   Должно показать что-то вроде `v22.x.x`

### 1.2. Запустите CRM на своём ПК

В PowerShell:

```powershell
cd "C:\Users\1\Desktop\workspace-files (2)"
npm install
npm run db:push
npm run setup:prod
npm run dev
```

Должна появиться строка:
```
AutoService CRM: http://localhost:4200
```

### 1.3. Откройте в браузере

1. Откройте **Chrome** или **Edge**
2. В адресной строке введите **точно**: `http://localhost:4200`
3. **Не используйте** `127.0.0.1` — иначе вход может не работать

### 1.4. Первый вход (экран логина)

На странице входа вы увидите:
- Поле **Email**
- Поле **Пароль**
- Кнопку **«Войти»**
- Ссылку **«Инициализировать систему»** (внизу)

**Если входите первый раз:**
1. Нажмите **«Инициализировать систему»**
2. Появится сообщение «Готово! admin@crm.local / admin123»
3. В поле **Email** введите: `admin@crm.local`
4. В поле **Пароль** введите: `admin123`
5. Нажмите **«Войти»**

Вы попадёте в CRM — слева меню: **Входящие**, **Клиенты**, **Заказы** и т.д.

> Локальный запуск (`npm run dev`) — только для проверки. Операторы **не смогут** работать, когда ваш ПК выключен. Для постоянной работы нужен сервер (Часть 2).

## Часть 2. Аренда сервера (VPS)

### 2.1. Заказ VPS на Timeweb (пример)

1. Зайдите на https://timeweb.cloud
2. Зарегистрируйтесь / войдите
3. Меню **«Облачные серверы»** → **«Создать сервер»**
4. Заполните:
   - **ОС:** Ubuntu 22.04
   - **Регион:** ближайший к вам (Москва)
   - **Конфигурация:** минимальная (1 CPU, 1 GB RAM)
   - **Имя сервера:** `crm-server` (любое)
5. Нажмите **«Создать»**
6. Дождитесь статуса **«Запущен»** (1–3 минуты)

### 2.2. Запишите данные для входа

В панели VPS найдите:
- **IP-адрес** — например `185.123.45.67`
- **Логин** — обычно `root`
- **Пароль** — пришлют на почту или покажут в панели

**Пример записи в блокнот:**
```
IP: 185.123.45.67
Логин: root
Пароль: MySecretPass2026!
```

## Часть 3. Подключение к серверу с Windows

### 3.1. Установите PuTTY (для команд)

1. Скачайте PuTTY: https://www.putty.org
2. Установите
3. Запустите **PuTTY**
4. В поле **Host Name** введите IP: `185.123.45.67`
5. Port: `22`
6. Нажмите **Open**
7. Первый раз спросит про ключ — нажмите **Yes**
8. Login: `root`
9. Password: вставьте пароль (в PuTTY символы **не видны** при вводе — это нормально) → Enter

Вы увидите приглашение вроде:
```
root@crm-server:~#
```
Это **терминал сервера** — сюда вводите команды из инструкции.

### 3.2. Установите WinSCP (для загрузки файлов)

1. Скачайте: https://winscp.net
2. Установите
3. Запустите **WinSCP**
4. **Протокол:** SFTP
5. **Имя хоста:** `185.123.45.67`
6. **Имя пользователя:** `root`
7. **Пароль:** ваш пароль
8. Нажмите **«Войти»**

Слева — ваш компьютер, справа — сервер.

## Часть 4. Загрузка CRM на сервер

### 4.1. Создайте папку на сервере

В PuTTY введите по очереди (после каждой строки — Enter):

```bash
mkdir -p /opt/crm
mkdir -p /opt/backups
```

### 4.2. Скопируйте файлы проекта

В **WinSCP**:
1. Справа откройте папку `/opt/crm`
2. Слева найдите папку `C:\Users\1\Desktop\workspace-files (2)`
3. Выделите **всё содержимое** папки проекта (кроме `node_modules` — её можно не копировать, она большая)
4. Перетащите на правую сторону (на сервер)

**Обязательно должны быть на сервере:**
- `package.json`
- `server.prod.ts`
- `server.ts`
- папки `api`, `src`, `scripts`
- `ecosystem.config.cjs`
- `.env.example`

Папку `node_modules` **не копируйте** — установим на сервере.

## Часть 5. Установка программ на сервере

В PuTTY (вы должны быть в терминале сервера):

```bash
cd /opt/crm

# Обновление системы
apt update && apt upgrade -y

# Node.js 20
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs nginx certbot python3-certbot-nginx

# PM2 — чтобы CRM не выключалась
npm install -g pm2

# Зависимости CRM
npm ci
```

Дождитесь окончания (может занять 5–15 минут).

## Часть 6. Настройка домена

### 6.1. Привязка домена к серверу

В панели, где купили домен (Reg.ru, Timeweb, Beget и т.д.):

1. Откройте **DNS-записи** / **Управление DNS**
2. Добавьте запись типа **A**:
   - **Имя / Subdomain:** `crm` (получится `crm.ваш-домен.ru`)
   - **Значение / IP:** `185.123.45.67` (ваш IP VPS)
   - **TTL:** 300 или по умолчанию
3. Сохраните

Подождите **15–60 минут**, пока DNS обновится.

Проверка (в PowerShell на своём ПК):
```powershell
ping crm.autoservice-moscow.ru
```
Должен отвечать ваш IP.

### 6.2. Файл настроек `.env`

В PuTTY:

```bash
cd /opt/crm
cp .env.example .env
nano .env
```

Откроется редактор. Введите (подставьте свой домен):

```env
PUBLIC_URL=https://crm.autoservice-moscow.ru
PORT=4200
```

**Как сохранить в nano:**
1. Ctrl+O → Enter (сохранить)
2. Ctrl+X (выйти)

## Часть 7. База данных

В PuTTY:

```bash
cd /opt/crm
npm run db:push
npm run setup:prod
npm run build
```

**Что это делает:**
- `db:push` — создаёт таблицы в файле `crm.db`
- `setup:prod` — проверяет миграции

### Создание первого администратора

Пока HTTPS ещё не настроен, можно через localhost на сервере:

```bash
curl -X POST http://localhost:4200/api/seed
```

Ответ должен быть: `{"ok":true,"message":"AutoService CRM готова..."}`

Если пишет `Already seeded` — админ уже есть, это нормально.

**Данные для входа:**
- Email: `admin@crm.local`
- Пароль: `admin123`

## Часть 8. Запуск CRM 24/7

```bash
cd /opt/crm
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup
```

После `pm2 startup` появится строка с командой — **скопируйте и выполните её** (начинается с `sudo env...`).

Проверка:
```bash
pm2 status
```

В колонке `status` должно быть **online**.

Логи (если что-то не работает):
```bash
pm2 logs crm
```

Выход из логов: Ctrl+C

## Часть 9. HTTPS (обязательно для Авито)

### 9.1. Настройка Nginx

```bash
nano /etc/nginx/sites-available/crm
```

Вставьте (замените домен на свой):

```nginx
server {
    listen 80;
    server_name crm.autoservice-moscow.ru;

    location / {
        proxy_pass http://127.0.0.1:4200;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

Сохраните: Ctrl+O, Enter, Ctrl+X

```bash
ln -s /etc/nginx/sites-available/crm /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx
```

### 9.2. Бесплатный SSL-сертификат

```bash
certbot --nginx -d crm.autoservice-moscow.ru
```

Certbot спросит:
1. **Email** — введите ваш email (для уведомлений о продлении сертификата)
2. Согласие с условиями — `Y`
3. Рассылка — можно `N`
4. Редирект на HTTPS — выберите **2** (Redirect)

### 9.3. Проверка в браузере

Откройте: `https://crm.autoservice-moscow.ru`

Должна открыться **страница входа** AutoService CRM.

## Часть 11. Добавление операторов

Каждый сотрудник, который отвечает клиентам, нужен как **Оператор**.

1. **Настройки** → вкладка **👥 Операторы**
2. Блок **«Добавить оператора»**

**Пример для Марии:**
| Поле | Что ввести |
|------|------------|
| Имя | `Мария` |
| Email | `maria@ваша-компания.ru` |
| Пароль | `MariaCRM2026!` |
| Роль | `Оператор` (в выпадающем списке) |

3. Нажмите **«+ Добавить»**
4. Повторите для каждого оператора

**Что сказать оператору:**
> Заходи на https://crm.autoservice-moscow.ru  
> Логин: maria@ваша-компания.ru  
> Пароль: MariaCRM2026!

Оператор видит: **Входящие**, **Клиенты**, **Заказы**, **Запись на ремонт** — но не может удалять каналы и других админов.

## Часть 12. Подключение Авито

### 12.1. Получите ключи на developers.avito.ru

1. Откройте https://developers.avito.ru
2. Войдите под аккаунтом Авито
3. **«Мои приложения»** → **«Создать приложение»**
4. Запишите:
   - **Client ID** — например `abc123xyz`
   - **Client Secret** — длинная строка, показывается один раз!
5. **User ID** — ID вашего аккаунта в Messenger API (есть в документации Авито или в личном кабинете разработчика)

### 12.2. В CRM

1. **Настройки** → **📡 Каналы**
2. Блок **«Добавить канал»**

| Поле | Пример |
|------|--------|
| Название | `Авито — основной магазин` |
| Тип | выберите **Авито** |
| Client ID | `abc123xyz` |
| Client Secret | вставьте секрет |
| User ID | `123456789` |
| Webhook Secret | можно оставить пустым |

3. Кнопка **«+ Подключить канал»**

### 12.3. Webhook в кабинете Авито

После подключения под каналом появится строка:
```
Webhook URL: https://crm.autoservice-moscow.ru/api/webhooks/avito/avito_1
```

1. Скопируйте этот URL целиком
2. В кабинете developers.avito.ru → ваше приложение → **Webhooks**
3. Вставьте URL
4. Сохраните

### 12.4. Проверка

1. В CRM нажмите кнопку **«Проверить»** рядом с каналом Авито
2. Напишите тестовое сообщение с Авито на своё объявление
3. В CRM слева **💬 Входящие** — должен появиться диалог (может занять до 1 минуты)

## Часть 16. Резервная копия базы (обязательно!)

Все данные в файле `/opt/crm/crm.db`. Если сервер сломается — без бэкапа потеряете всё.

**Ручной бэкап (раз в день):**
```bash
cp /opt/crm/crm.db /opt/backups/crm-$(date +%F).db
```

**Автоматический бэкап каждую ночь в 3:00:**
```bash
crontab -e
```

Выберите редактор `1` (nano), в конец файла добавьте:
```
0 3 * * * cp /opt/crm/crm.db /opt/backups/crm-$(date +\%F).db
```

Сохраните Ctrl+O, Enter, Ctrl+X.

Скачать бэкап на свой ПК: через **WinSCP** — папка `/opt/backups/`.

## Часть 18. Частые проблемы

### «Не могу войти» / «Сетевая ошибка»
- Проверьте `pm2 status` — должно быть **online**
- `pm2 logs crm` — смотрите ошибки
- Открываете ли вы **https://** а не http://

### Авито не присылает сообщения
- `PUBLIC_URL` в `.env` должен быть **https://ваш-домен** (без слэша в конце)
- Webhook в Авито = точный URL из **Настройки → Каналы**
- Нажмите **«Проверить»** у канала

### CRM выключилась после перезагрузки сервера
```bash
pm2 resurrect
# или
cd /opt/crm && pm2 start ecosystem.config.cjs && pm2 save
```

### Забыли пароль оператора
Админ: **Настройки → Операторы** — пока нет кнопки сброса, создайте нового оператора с новым email или попросите разработчика сбросить в базе.

### Страница белая / 502 Bad Gateway
```bash
cd /opt/crm
npm run build
pm2 restart crm
systemctl status nginx
```
